# Arquearia Brasil

Site de um clube de tiro com arco com loja virtual integrada. Comecei em 2023 como um dos meus primeiros sites, só com HTML e CSS, e depois voltei nele para transformar em algo com cara de produto de verdade.

O clube e a loja são fictícios: nenhum pedido é cobrado ou entregue.

## O que tem

- **Landing page:** apresentação do clube, modalidades (recurvo, composto e campo), como começar, planos, benefícios, destaques da loja e horários
- **Loja:** 14 produtos em 5 categorias, com filtro por categoria (que vai para a URL) e ordenação por preço ou nome
- **Página de produto:** ficha técnica, quantidade e produtos relacionados
- **Carrinho:** gaveta lateral em todas as páginas, com quantidade e total, salvo no navegador
- **Finalizar pedido:** dados de contato, retirada no clube ou entrega (com endereço obrigatório só na entrega), validação e confirmação
- **Diretrizes, inscrição e créditos das fotos**

## Tecnologias

HTML, CSS e JavaScript puro, sem framework e sem etapa de build. O catálogo fica em [`js/produtos.js`](js/produtos.js): para adicionar um produto, basta incluir um item na lista.

## Como abrir

Baixe o projeto e abra o `index.html` no navegador.

```bash
git clone https://github.com/nardomaciel/arqueirosbr.git
```
